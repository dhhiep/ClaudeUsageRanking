Privacy Policy

Claude Usage Ranking Chrome Extension — Last updated: March 2026

Claude Usage Ranking does not collect, store, or transmit any personal user data to any external server or third party.

Data Access

The extension accesses the following data solely to display Claude API usage information from platform.claude.com:

  • Session cookie — read once per request to authenticate API calls to platform.claude.com. Never stored, logged, or transmitted elsewhere.
  • Organization & workspace IDs — read from the Claude platform page DOM. Stored only in local Chrome storage within your browser.
  • Usage data — fetched from platform.claude.com and cached locally per date for performance. Never leaves your browser.

Local Storage Only

All data persisted by this extension is stored exclusively in Chrome's local storage on your device. This includes:

  • Cached usage data (per-date)
  • User preferences (theme, cache mode, date range)
  • Organization and workspace IDs

No External Transmission

The extension makes network requests only to https://platform.claude.com — the same domain you are already authenticated with. No data is sent to any other server, including the developer's servers.

No Tracking

The extension contains no analytics, telemetry, advertising SDKs, or tracking of any kind.

Permissions

  • cookies — authenticate API requests to platform.claude.com
  • storage — cache usage data and preferences locally in your browser
  • tabs — detect navigation to the Claude platform cost page for auto-sync
  • sidePanel — display the ranking UI in Chrome's side panel
  • host_permissions: platform.claude.com — scope all requests strictly to Anthropic's platform
